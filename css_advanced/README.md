CSS Advanced — ALX Frontend Project

This project builds on the HTML, advanced** project by adding full visual styling using pure CSS.  
The goal is to recreate the final design shown in the provided Figma file using clean, responsive, and well-structured CSS — without using any external libraries or frameworks.

---

 Project Overview

In this project, I will:

- Build the full layout and visual design of the website using **only HTML and CSS**.
- Implement the styles to match the design prototype given in Figma.
- Ensure the website is fully responsive and aligns with modern frontend best practices.
- Validate all code using **W3C validators**.
- Follow a clean folder structure and maintain readable, organized code.

The website includes:

- A navigation header  
- Hero/banner section  
- Quote/testimonial section  
- Tutorials section  
- Membership section  
- FAQ section  
- Footer
